# Acceptance Test: T4.3 Speaker/Signer Attribution

Status: PASS
Date: 2026-11-08

## Summary
Implements visual scene-based speaker and signer attribution via `attribute_speaker` and utterance prefix formatting via `format_attributed_text`.

## 6-Case Attribution Matrix
1. **0 People / Stale Cache**: Returns `"unknown"`.
2. **1 Known Person**: Resolves directly to person's name (e.g. `"Jud"`).
3. **1 Unknown Person**: Falls back to `"unknown"` when name is generic/empty (`unknown`, `person`, `stranger`, `?`).
4. **2 People (Single center+near Candidate)**: Resolves to the center-near candidate (`"Jud"`).
5. **2 People (Multiple center+near Candidates)**: Ambiguous attribution returns `"unknown"`.
6. **2 People (Neither center+near)**: Ambiguous attribution returns `"unknown"`.

## Formatting
- `format_attributed_text(text, scene_or_cache)` produces `"[Speaker]: text"` when speaker != `"unknown"`, otherwise leaves text unprefixed.
