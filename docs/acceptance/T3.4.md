# Acceptance Test Report: T3.4 Text-to-speech

- `TextToSpeech` engine in `brain/audio/tts.py`:
  - Deterministic fallback tone generator and Piper voice model synthesis support.
  - Sentence-level audio synthesis and streaming chunk playback into `AudioSink`.
  - Stream token sentence splitting and multi-sentence playback via `split_sentences`.
  - Responsive cancellation via threading events and immediate sink termination.
