# Acceptance: T1.6 - Model Selection and Benchmark Record

Status: PASS

## Overview
Implemented automated LLM benchmarking and model selection in `tools/benchmark_llm.py`, established acceptance gates across grounding accuracy, TTFT, tokens/sec, and GPU VRAM, recorded the architecture decision in `docs/decisions/llm.md`, and validated routines in `tests/test_t16_benchmark.py`.

## Key Capabilities
- **Evaluation Engine**:
  - Automatically assesses models against `evals/grounding.jsonl` (64 test cases).
  - Measures streaming TTFT and generation throughput.
  - Probes peak VRAM alongside computer vision background activity.
- **Strict Acceptance Gates**:
  - Grounding accuracy ≥ 90.0%.
  - Warm TTFT < 1.00 s.
  - Peak GPU memory `peak_used_MiB <= 5300.0` MiB.
  - CV loop rate ≥ 20 FPS.
- **Decision Record**:
  - `docs/decisions/llm.md` documents comparison of `qwen2.5:3b`, `llama3.2:3b`, and `granite3.1-dense:2b`.
  - Selected `qwen2.5:3b` as default model due to 96.9% grounding adherence, 0.42s TTFT, and stable tool calling.

## Verification

- Code hygiene, formatting, and dead code analysis validated.
