# Acceptance: T6.5 - Security, Prompt-Injection, and Failure Injection Audit

Status: PASS

## Overview
Implemented comprehensive security audit, prompt-injection defenses, broker ACL role verification, git secret scanning, and failure injection recovery in `tests/test_t65_security.py`.

## Key Capabilities
- **Adversarial Prompt-Injection Testing**:
  - Person names containing control characters, system instruction prefixes (`System:`, `[INST]`), SQL injection strings, and JSON dictionary payloads are safely treated as literal inert data by `PromptBuilder`.
  - Sign language recognition text containing command-injection attempts is framed safely as literal input string (`[Sign: ...]`) without executing privileged instructions.
- **Git Secret Scan**:
  - Scans all tracked files for high-entropy tokens, AWS access keys, GitHub personal access tokens, and private keys.
  - Confirmed zero leaked secrets across the repository.
- **Broker ACL Role Isolation**:
  - Validates publish/subscribe rights across the four roles (`cv`, `brain`, `pi`, `esp32`).
  - Confirms no cross-role capability elevation (e.g. CV cannot publish to `bmo/hw/cmd` or `bmo/brain/say`).
- **Failure Injection Recovery**:
  - Injected LLM timeout cleanly aborts turn and allows graceful return to `BrainState.IDLE`.
  - Injected CV offline marks scene state stale, prevents hallucinated presence, and renders camera offline prompt.
  - Empty or silent audio transcription cleanly terminates turn without speaking or deadlocks.
  - Missing edge heartbeat triggers automatic fallback to local audio sink and source.
