# Acceptance: T3.5 - Turn Manager with Barge-In and Echo Handling

Status: PASS

## Overview
Implemented `TurnManager` in `brain/turn.py` orchestrating voice interactions, echo suppression during TTS audio playback, sub-300ms barge-in interruption, and clean thread lifecycle management.

## Key Capabilities
- **Echo Suppression**: While `BrainState.SPEAKING`, audio frames only query `WakeWordDetector` (never `VoiceActivityDetector`). High RMS TTS playback from BMO's own speakers will never falsely trigger turns or barge-ins.
- **Fast Barge-In (< 300 ms)**: Immediate signaling via `cancel_event`, `tts.cancel()`, `sink.stop()`, active thread join (timeout 250ms), and transition to `BrainState.LISTENING` with zero orphan background threads.
- **Full Voice Turn**: Clean pipeline execution `IDLE -> LISTENING -> THINKING -> SPEAKING -> IDLE`, streaming sentences through `SentenceSplitter`, publishing `BrainSay` with `Emotion.HAPPY` on `BRAIN_SAY`, and invoking turn metrics callbacks.

- Hygiene, formatting, and dead-code checks confirmed clean.
