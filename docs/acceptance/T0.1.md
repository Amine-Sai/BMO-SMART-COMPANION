## Summary of Changes

1. **Contracts Package (`bmo_contracts/`)**:
   - Implemented PEP 621 package `bmo-contracts` (v0.1.0) with Pydantic v2 strict models (`ConfigDict(extra="forbid")`).
   - Implemented models: `Emotion`, `VisionStatus`, `BrainStatus`, `HwStatus`, `HwEvent`, `FaceData`, `PersonData`, `PersonLeftData`, `SignData`, `ObjectData`, discriminated union `Event` (`FaceIdentified`, `PersonDetected`, `PersonLeft`, `SignRecognized`, `ObjectSeen`), `ScenePerson`, `LastSign`, `Scene`, `VisionCmd`, `VisionCmdResult`, `BrainSay`, `HwCmd`.
   - Implemented topics registry in `bmo_contracts/topics.py` with `TopicSpec` dataclass and 10 canonical topics (`VISION_STATUS` through `HW_EVENT`) plus backward-compatible legacy constants.
   - Installed `bmo-contracts` editable into `.venv` and updated `requirements.lock.txt`.

2. **Tooling & Linter Configuration**:
   - Created `pytest.ini` with testpaths and markers (`gpu`, `slow`, `hw`, `broker`).
   - Created `ruff.toml` enforcing line length 120, lint rules (`F`, `ARG`, `ERA`, `B`), and dummy variable pattern.

3. **Topic Literals Elimination**:
   - Replaced all `"bmo/..."` string literals across `assistant_cv/config.py`, `tools/mqtt_client.py`, `tests/test_mqtt_commands.py`, and `tests/test_pipeline_upgrades.py` with imports from `bmo_contracts.topics`.
   - Verified zero `"bmo/` string literals exist outside `bmo_contracts/topics.py` across all Python source files.

4. **CV Pipeline Conformance**:
   - Added `ShortTermMemory.get_scene_contract()` in `assistant_cv/memory.py` mapping `"close" -> "near"`, computing `since_s`, `objects: list[str]`, `last_sign`, and compact `recent` summary (<= 300 tokens).
   - Updated `assistant_cv/mqtt_bridge.py` to configure LWT on `VISION_STATUS`, publish online status on connect and offline on disconnect, subscribe to `VISION_CMD`, add `publish_scene` (validating against `Scene`), and normalize the 5 contract events in `publish_event` with monotonic ID counter.
   - Updated `EventDetector` in `assistant_cv/main.py` to emit contract-aligned data fields (`track_id`, `pos`, `proximity`, `conf`, `text`, `object_seen`) and wired `publish_scene` on scene signature changes throttled to max 1 Hz.

5. **Test Suites & Documentation**:
   - Created `tests/test_hygiene.py` covering all 7 repository hygiene invariants (0 topic literals, 0 python3.12/.venv-brain references, settings key uniqueness, lockfile sync, uv pip check overrides, ACL generator sync, FakeLLMBackend scoping).
   - Created `tests/test_t01_contracts.py` verifying all 14 Section 4.3 JSON examples, strict rejection of extra/malformed fields, scene contract token budgeting, and MQTT bridge conformance.
   - Created `docs/contracts.md` documenting topics, models, and Section 4.3 JSON examples.
