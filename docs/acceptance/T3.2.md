# Acceptance Test Report: T3.2 Wake Word and VAD

## Status: PASS

### Overview
Implementation of the wake word detector and voice activity detector for the audio ingest pipeline:
- `brain/audio/wake.py`: `WakeWordDetector` with openWakeWord lazy loader, frame scoring, refractory cooldown tracking with monotonic clock injection, and state reset.
- `brain/audio/vad.py`: `VoiceActivityDetector` with Silero VAD / RMS energy fallback, probability thresholding, and silence-bounded utterance collection with early stopping.

### Verification Results
- Recall: >= 90% detection rate across 20 positive wake events spaced beyond cooldown.
- Refractory Cooldown: duplicate wake triggers blocked within 2.0 s refractory window.
- False Wake Rejection: 0 false wakes on 10 minutes (30,000 frames) of Gaussian background noise.
- Utterance Segmentation: correctly segmented 45 frames (25 speech + 20 trailing silence) from 10 silent + 25 speech + 25 silent frame stream, stopping early with remaining frames left unread.
- Pure Silence: returns `None` without false segmentation.
- Code Hygiene: ruff formatting, strict linting (`F`, `ARG`, `ERA`, `B`), and vulture confidence checks passed.
