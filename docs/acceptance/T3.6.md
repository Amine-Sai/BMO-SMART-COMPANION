# Acceptance: T3.6 - Latency Instrumentation and Percentile Tracking

Status: PASS

## Overview
Implemented turn-level latency instrumentation in `brain/telemetry.py` and integrated it with `TurnManager`. Provides structured logging via `JSONLLogger`, robust percentile calculation (`p50`, `p95`), and metric summaries.

## Key Capabilities
- **TurnMetrics Dataclass**: Captures pipeline latencies including `vad_end_ms`, `stt_ms`, `llm_ttft_ms`, `tts_first_chunk_ms`, `total_ms`, `utt_id`, and timestamp `ts`.
- **LatencyTracker**:
  - Ingests turn metrics from dictionaries or dataclass instances with fallback support (`e2e_voice_ms` -> `turn_ms` -> `total_ms`).
  - Emits structured `turn_latency` events to `JSONLLogger`.
  - Serves as the callback hook `on_turn_metrics` for `TurnManager`.
  - Calculates `p50` (median) and `p95` (95th percentile) metrics using `numpy.percentile`.
  - Generates comprehensive summaries (`p50`, `p95`, `min`, `max`, `count`) across all metric dimensions.
