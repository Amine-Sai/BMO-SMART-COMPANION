## Implementation Overview
- `STTResult`: Immutable dataclass containing `text: str`, `confidence: float`, `latency_ms: float`.
- `SpeechToText`:
  - Silence gating via RMS energy calculation: Drops audio segments with RMS < 150 before inference.
  - Testable injection via `transcribe_fn`: Allows deterministic unit testing without requiring whisper model downloads.
  - Confidence and blank filtering: Utterances with confidence < 0.4 (no_speech_prob > 0.6) or whitespace-only transcriptions are dropped returning `None`.
  - Latency tracking: Precise latency tracking using injected monotonic clock.
