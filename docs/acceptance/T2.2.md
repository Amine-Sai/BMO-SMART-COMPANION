# Acceptance: T2.2 (Read-only scene tools)

Status: PASS

## Summary
Implemented read-only scene tools for the BMO Assistant brain tool layer:
- `SceneTools` class providing `get_scene`, `find_object`, and `list_people` queries.
- `register_scene_tools(registry, scene_cache)` function registering `ToolSpec` entries on `ToolRegistry`.
- Stale scene cache detection returning `{"ok": False, "error": "scene_stale"}` across all three tools when scene is missing, clock expired, or vision status is offline.
- Case-insensitive object matching for `find_object`.
