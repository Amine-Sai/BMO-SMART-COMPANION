# Acceptance Test: T2.5 Actuator Tools & Limits Header

Status: PASS

## Scope
- `brain/tools/actuator_tools.py`: Actuator tools (`move_servo`, `set_expression`, `play_sound`) with limits clamping and rate limiting.
- `tools/gen_limits_header.py`: Generation of C header `edge/esp32_firmware/limits.h` from `config/limits.yaml`.
- `tests/test_t25_actuator_tools.py`: Unit and integration test suite covering limits clamping, rate limiting, tool registry dispatch, and header parity.

## Verification
- Limits loaded from `config/limits.yaml` unpacking `rate_limits`.
- `move_servo(id="pan", angle=500)` clamps to `60.0` (`clamped: True`) and publishes `HwCmd` to `bmo/hw/cmd`.
- 20 rapid `move_servo` calls within 1.0s spaced by 0.05s yield exactly 4 successful publishes spaced by `>= 0.25s`, others return `{"ok": False, "error": "rate_limited"}`.
- `ToolRegistry.dispatch` invokes `set_expression` and `play_sound` (valid `"chime"` succeeds, unknown `"laser"` returns `{"ok": False, ...}`).
- Generated C header matches `edge/esp32_firmware/limits.h`.
