- Status: PASS

## Summary of Implementation

1. **`tools/mock_cv.py`**:
   - Implemented `MockCV` peer authenticating as `cv`/`cv_insecure_dev_password` with `CallbackAPIVersion.VERSION2`.
   - Subscribes to `VISION_CMD`, publishes retained `VisionStatus(online=True)` on `VISION_STATUS`.
   - Provides `publish_event(event)` and `publish_scene(scene)`.
   - Handles `VISION_CMD` by validating via `VisionCmd.model_validate_json` and publishing `VisionCmdResult(id=cmd.id, ok=True, detail=f"ack:{cmd.cmd}")` to `VISION_CMD_RESULT`.
   - Provides CLI interface with `--host`, `--port`, and `--scenario` (`greeting`, `sign`, `cmd_echo`).

2. **`tools/mock_pi.py`**:
   - Implemented `MockPi` peer authenticating as `pi`/`pi_insecure_dev_password`.
   - Subscribes to `BRAIN_SAY`, `HW_CMD`, `BRAIN_STATUS`, `VISION_STATUS`.
   - Publishes retained `HwStatus(online=True, ts=..., capabilities=[...])` on `HW_STATUS`.
   - Provides `publish_hw_event(event)`.
   - Records received `say_messages: list[BrainSay]`, `hw_commands: list[HwCmd]`, `brain_statuses`, and `vision_statuses`.
   - Provides CLI interface with `--host`, `--port`, and `--scenario` (`mute_toggle`, `heartbeat`).

3. **`tests/test_contracts_roundtrip.py`**:
   - Runs `SimpleMQTTBroker` on port 18893 with ACL authorization and user authentication in a background daemon fixture.
   - Connects `MockCV`, `MockPi`, and `brain` client.
   - Iterates through all 10 `TopicSpec` entries in `TOPICS.values()`, validating payload serialization and roundtrip receipt.
   - Tests all 5 `Event` variants on `VISION_EVENTS` (`FaceIdentified`, `PersonDetected`, `PersonLeft`, `SignRecognized`, `ObjectSeen`) using `validate_json` and `parse_event_json`.
   - Verifies `MockCV` command execution roundtrip (`VISION_CMD` -> `VISION_CMD_RESULT`).
   - Verifies `MockPi` commands and hardware events (`BRAIN_SAY`, `HW_CMD`, `HW_EVENT`).
