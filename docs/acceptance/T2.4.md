# Acceptance: T2.4 Identity Tools (`remember_person`, `forget_person`)

Status: PASS

## Summary
Implemented identity tools integration with VisionClient:
- `IdentityTools.remember_person`: invokes `VisionClient.enroll` and formats return dictionary.
- `IdentityTools.forget_person`: invokes `VisionClient.forget` and formats return dictionary.
- `register_identity_tools`: registers `remember_person` (unconfirmed/safe) and `forget_person` (risky, requires confirmation) into `ToolRegistry`.

## Verification
- `remember_person` dispatches via `ToolRegistry`, publishes `VisionCmd(cmd="enroll", args={"name": "Jud", "shots": 8})` on `VISION_CMD`, and returns success upon `VisionCmdResult`.
- `forget_person` unconfirmed dispatch returns `{"ok": False, "needs_confirmation": True, "tool": "forget_person", ...}` and publishes 0 messages.
- `forget_person` confirmed dispatch publishes `VisionCmd(cmd="forget", args={"name": "Jud"})` and returns success.
- `forget_person` propagates failure and timeout with `ok: False`.
