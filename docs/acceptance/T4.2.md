# Acceptance Criteria: T4.2 Proactive Event Policy

Status: PASS

## Overview
Implemented proactive event policy engine (`ProactivePolicy`) and configuration schema (`PolicySettings`) governing autonomous greetings and walk-by suppression.

## Components Implemented
1. `config/settings.d/policy.yaml`:
   - Configured threshold parameters: `face_min_conf: 0.65`, `greeting_cooldown_s: 900.0`, `global_cooldown_s: 30.0`, `walk_by_window_s: 1.5`, `sign_min_conf: 0.75`, `sign_debounce_s: 2.0`, `idle_unload_s: 300.0`.
2. `brain/settings.py`:
   - Added `PolicySettings` model with frozen configuration and forbidden extra fields.
   - Updated root `Settings` schema with optional `policy: PolicySettings | None = None`.
3. `brain/policy.py`:
   - Implemented `ProactivePolicy` handling `FaceIdentified`, `PersonDetected`, and `PersonLeft` events.
   - Per-person cooldown (`900s`) and global cooldown (`30s`).
   - Walk-by window filtering (`1.5s`) via `tick()` polling.
   - Non-IDLE state greeting suppression preventing speech during `LISTENING`, `THINKING`, `SPEAKING`, `MUTED`, or `ERROR`.
4. `tests/test_t42_policy.py`:
   - Verified 50 rapid face identifications produce exactly 1 greeting and allow subsequent greeting after +901s.
   - Verified walk-by events (presence < 1.5s) produce 0 greetings.
   - Verified state machine non-IDLE suppression.
   - Verified settings loading and validation from YAML.
